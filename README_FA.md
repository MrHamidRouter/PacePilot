# PacePilot Studio v2.1

### اجرای Administrator و محدودسازی FPS (نسخه ۲.۱.۱)

فایل `PacePilot.exe` با Manifest استاندارد Windows درخواست دسترسی **Administrator** می‌دهد؛ درخواست UAC طبیعی و قابل انتظار است. این نسخه بررسی زودهنگام مقدار FPS را اصلاح می‌کند و پس از Save/Update، مقدار پروفایل RTSS روی دیسک و در API را بازخوانی می‌کند. از بخش **Game Profiles** پروفایل بازی موردنظر را انتخاب کرده و FPS را اعمال کنید. محدودکننده همچنان به سازگاری بازی با RTSS وابسته است.

**نکته:** فعال بودن گزینه Start with Windows به معنی اجرای بی‌صدای برنامه با Administrator نیست. ویندوز بدون تأیید UAC، اجرای خودکار با دسترسی بالاتر را تضمین نمی‌کند؛ این بسته هیچ راهکار دورزدن UAC یا SmartScreen ندارد.


**توسعه‌دهنده: Mr.HamidRouter**

PacePilot نرم‌افزار ویندوزی محدودسازی FPS با استفاده از RTSS است. برنامه دارای **۶ رابط گرافیکی واقعی و قابل‌تغییر** و پشتیبانی از زبان‌های فارسی و انگلیسی است. همه طرح‌ها به تنظیمات مشترک، پروفایل‌های واقعی بازی و موتور RTSS متصل‌اند.

### دریافت و نصب

فقط یک ZIP نیاز است: `PacePilot-Windows-x64.zip` که از [GitHub Actions](https://github.com/MrHamidRouter/PacePilot/actions/workflows/windows-build.yml) قابل دریافت است.

فایل ZIP را استخراج کنید. اگر RTSS نصب نیست، یک بار **`Setup-PacePilot.bat`** را اجرا کنید؛ ابتدا وجود RTSS بررسی می‌شود، سپس در صورت نیاز فرمان زیر اجرا می‌شود و برنامه باز می‌شود:

```bat
winget install --id Guru3D.RTSS --exact --source winget --silent --accept-package-agreements --accept-source-agreements --disable-interactivity
```

اگر RTSS نصب است، کافی است `PacePilot.exe` را اجرا کنید. در صورت نیاز، ویندوز تأیید مجوز مدیر را درخواست می‌کند.

### امکانات

- شش طرح: فیروزه‌ای، سفید/آبی، بنفش سایبری، قرمز مسابقه‌ای، سبز گیمینگ، مشکی/طلایی؛ با انتخاب فوری از داخل برنامه.
- فارسی و انگلیسی با ذخیره زبان در تنظیمات.
- FPS آماده و سفارشی از ۰ تا ۱۰۰۰؛ صفر = بدون محدودیت.
- پروفایل اختصاصی هر بازی، افزودن فایل EXE و انتخاب از برنامه‌های در حال اجرا.
- مشاهده FPS و زمان فریم واقعی از حافظه اشتراکی RTSS، بدون اطلاعات جعلی.
- کلیدهای `Alt+Shift+L` و `Alt+Shift+↑/↓`، اجرای خودکار، Tray و Always on Top.
- نصب RTSS فقط بعد از اجازه کاربر با `winget`، تشخیص نصب قبلی و جایگزین دانلود رسمی.
- عیب‌یابی RTSS و تست خودکار رابط کاربری.

### نصب RTSS

در اولین اجرا و در صورت نبود RTSS، از شما برای دانلود و نصب خودکار با Windows Package Manager اجازه گرفته می‌شود. ممکن است پنجره مجوز Administrator ظاهر شود. در صورت عدم امکان نصب، [صفحه رسمی RTSS](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/) معرفی می‌شود.

### محدودیت‌های مهم

این برنامه رابط کاربری مستقلی بر پایه RTSS است، نه موتور اختصاصی FramePacer. قابلیت‌های NVIDIA Reflex، DLSS Dynamic MFG/Frame Generation و تزریق اختصاصی فریم **در این نسخه پیاده‌سازی نشده‌اند**. بازی‌های دارای سیستم ضدتقلب ممکن است استفاده از ابزارهای محدودکننده خارجی را ممنوع کنند. تست خودکار به‌معنای تأیید عملکرد در تمام بازی‌ها نیست.

**سورس برنامه: MIT | پلتفرم: Windows 10/11 x64 | نیازمند .NET Framework 4.x**

### قابلیت‌های نسخه ۲.۱

- گالری شش پوسته با تصاویر منتخب، پس‌زمینه تصویری و کنترل‌های قابل‌کلیک؛ تصاویر داخل EXE قرار دارند.
- شناسایی بازی‌های نصب‌شده با اسکن محلی کتابخانه‌های Steam، Epic Games و GOG؛ بعضی عناوین نیازمند انتخاب دستی هستند.
- بررسی نسخه جدید در GitHub Releases حداکثر روزی یک بار یا با دکمه «بررسی بروزرسانی». نصب بروزرسانی خودکار نیست.
- مدیریت مجوز ذخیره تنظیمات RTSS: اگر ویندوز اجازه نوشتن در Program Files ندهد، فقط برای ترمیم پروفایل با تأیید کاربر از UAC استفاده می‌شود.
- برای اولین استفاده ZIP را استخراج کنید؛ اگر RTSS نصب نیست، Setup-PacePilot.bat را اجرا کنید.

## نسخه آزمایشی ۲.۲ — OSD واقعی و سنسورهای سخت‌افزار

- برنامه همچنان **PacePilot واحد** است؛ کنترل FPS، شش پوسته تصویری، کتابخانه بازی‌ها و نمایش اطلاعات در همان فایل اجرایی‌اند.
- در بخش «پایش و نمایش بازی» کلید **Alt + Shift + O** را برای فعال/غیرفعال‌کردن OSD داخلی RTSS استفاده کنید. OSD از یک slot اختصاصی حافظه مشترک RTSSSharedMemoryV2 استفاده می‌کند؛ بدون تزریق مستقل به بازی.
- FPS، زمان فریم و نوار ۲۰ بخشی زمان فریم فقط از **اندازه‌گیری واقعی RTSS** گرفته می‌شوند؛ اگر بازی پشتیبانی نشود، خط تیره نشان داده می‌شود.
- CPU و RAM با شمارنده‌های بومی ویندوز خوانده می‌شوند. برای دمای CPU/GPU، مصرف GPU، کلاک GPU، توان GPU، VRAM و VRM برنامه HWiNFO64 را در حالت Sensors باز و **Shared Memory Support** را فعال کنید. مقادیر سنسورهای ناموجود «—» هستند.
- وجود سرویس BattlEye، EAC یا Riot در پس‌زمینه **به‌تنهایی** دلیل مسدودکردن تنظیمات یک بازی دیگر نیست. بااین‌حال بازی‌های محافظت‌شده مانند PUBG، Valorant و Fortnite همچنان از مداخله RTSS توسط PacePilot مستثنا هستند؛ **هیچ دورزدن ضدتقلب وجود ندارد**. برای این بازی‌ها محدودکننده داخلی بازی توصیه می‌شود.
- عملکرد واقعی محدودکننده و OSD روی سخت‌افزار و بازی هدف باید آزمایش شود؛ تست CI به‌تنهایی تضمین سازگاری نیست.


## نسخه ۲.۳ — شش پوسته، نمودار فریم واقعی و آمادگی رم

موتور کنترل FPS قبلی، کتابخانه بازی‌ها، OSD با میانبر `Alt + Shift + O`، پروفایل‌ها و بررسی آپدیت **در همان فایل اجرایی حفظ شده‌اند**. صفحه اصلی اکنون برای هر شش پوسته ساختار هماهنگی دارد و از تصاویر تعبیه‌شده، رنگ‌بندی اختصاصی و کارت‌های گرافیکی استفاده می‌کند. این رابط کنترل‌های قابل‌استفاده ویندوز است و **تصاویر طراحی‌شده صرفاً مرجع بصری‌اند؛ انطباق پیکسلی تضمین نمی‌شود**.

### نوار فعالیت Frame Time
نوار فعالیت و نمودار فقط از **نمونه‌های واقعی RTSS** به‌روزرسانی می‌شوند. نصب و اجرای RTSS یا ذخیره محدودیت FPS به‌معنای دریافت خودکار اطلاعات فریم بازی نیست. اگر بازیِ انتخاب‌شده اتصال Render Hook نداشته باشد، به‌جای نمایش داده ساختگی، پیام «در انتظار اتصال RTSS به بازی» دیده می‌شود. فایل‌های کمکی مانند `UnrealCEFSubProcess.exe` را به‌عنوان فایل اصلی بازی انتخاب نکنید. نمایش OSD روی بازی‌های دارای ضدتقلب تضمین نمی‌شود.

### بررسی رم قبل از بازی
با دکمه **بررسی و آماده‌سازی** می‌توان حافظه فیزیکی را ارزیابی کرد و حافظه کاری **خود PacePilot** را (اختیاری و به درخواست کاربر) کاهش داد. گزینه **برنامه‌های پرمصرف** موارد سنگینِ قابل‌مشاهده را معرفی می‌کند. هیچ برنامه‌ای به‌زور بسته نمی‌شود؛ کش/Standby ویندوز دستکاری نمی‌شود و افزایش FPS تضمین نیست. پس از بررسی، بازی را از طریق Steam یا میانبر عادی اجرا کنید.

اطلاعات GPU و VRM از حسگرهای واقعی HWiNFO64، در صورت موجود بودن، گرفته می‌شود؛ داده ناموجود با «—» نمایش داده می‌شود.


## نسخه ۲.۴ — رابط گرافیکی واقعی به‌جای عکس پس‌زمینه

شش پوسته (Neon Teal، Windows Blue، Cyber Purple، Racing Red، Esports Lime، Graphite Gold) اکنون با کنترل‌ها، گرادیان‌ها، کارت‌های گرد، سایدبار و هدر **برداری و واقعی** ساخته می‌شوند و تصویرِ اسکرین‌شات طراحی، پشت فرم کشیده نمی‌شود. تصاویر گالری پوسته نیز نمای واقعی اجزای رابط هستند. نمودار Frame Time فقط از داده‌های واقعی RTSS پر می‌شود و هنگام نبودن داده پیام مشخص نمایش می‌دهد. موتور RTSS، انتخاب بازی، OSD، پایش سخت‌افزار، آماده‌سازی امن رم و بررسی آپدیت دست‌نخورده حفظ می‌شوند.

توجه: هدف یک رابط بومی باکیفیت با الهام از طرح‌های مرجع است، نه کپی پیکسلی تصاویر. موفقیت کامپایل به‌تنهایی سازگاری نمایش روی هر مانیتور و بازی را ثابت نمی‌کند.

## نسخه ۲.۴.۱ — خواندن واقعی GPU / VRAM / VRM

این نسخه ظاهر نسخه ۲.۴ را حفظ می‌کند، اما خواندن سنسورهای GPU را مستقل از RTSS توسعه می‌دهد:

- ابتدا داده‌های HWiNFO64 Shared Memory را می‌خواند (در حالت Sensors-only و با گزینه Shared Memory Support فعال).
- اگر این داده‌ها موجود نباشند، به‌صورت خودکار و در پس‌زمینه، داده‌های WMI نرم‌افزارهای **LibreHardwareMonitor** و **OpenHardwareMonitor** و برخی شمارنده‌های GPU ویندوز را بررسی می‌کند.
- کارت‌های GPU، VRAM، توان، دما و VRM فقط مقادیر موجود را نمایش می‌دهند؛ برای سنسورهای غایب همچنان «—» نمایش داده می‌شود. شمارنده‌های ویندوز به‌تنهایی دما و توان GPU/VRM را فراهم نمی‌کنند. برخی مادربردها نیز سنسور VRM ندارند.
- روی یکی از کارت‌های خالی GPU/VRM کلیک کنید تا وضعیت منبع سنسور و راهنمای اتصال را ببینید.
- در نسخه رایگان HWiNFO، Shared Memory Support می‌تواند بعد از ۱۲ ساعت اجرای مداوم غیرفعال شود؛ باید دوباره فعالش کنید.

برای بررسی: **HWiNFO64 → Sensors-only → Main Settings → Shared Memory Support**؛ در صورت نبود این منبع، LibreHardwareMonitor را با حسگرهای فعال اجرا کنید. این تغییرها افزایش FPS را تضمین نمی‌کنند.
