# 🇮🇷 PacePilot 1.4 — راهنمای فارسی

**توسعه‌دهنده: Mr.HamidRouter**

## اجرای راحت با یک فایل EXE

از [GitHub Actions](https://github.com/MrHamidRouter/PacePilot/actions/workflows/windows-build.yml) جدیدترین اجرای موفق `Windows EXE build and self-test` را باز کنید. بسته `PacePilot-Windows-x64-v1.4` را دریافت و استخراج کنید و فقط `PacePilot.exe` را اجرا کنید. نیازی به Visual Studio یا فایل CMD نیست.

اگر فقط سورس را دارید، یک بار فایل `Start-PacePilot.cmd` را اجرا کنید تا فایل `Bin\PacePilot.exe` ساخته و تست شود.

## دانلود و نصب خودکار RivaTuner (RTSS)

هنگام اجرای برنامه، RTSS بررسی می‌شود. اگر نصب نیست، برنامه **اجازه** دانلود و نصب RTSS را می‌پرسد. با انتخاب «بله»، دستور نصب رسمی `winget install --id Guru3D.RTSS --exact ...` اجرا شده و در صورت لزوم ویندوز اجازه Administrator می‌خواهد. پس از نصب، برنامه RTSS را شناسایی و اجرا می‌کند. در صورت موجودبودن RTSS نیازی به نصب مجدد نیست.

چنانچه winget روی ویندوز موجود نباشد، اینترنت در دسترس نباشد، نصب رد شود یا خطایی رخ دهد، برنامه لینک [دانلود رسمی RTSS در Guru3D](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/) را پیشنهاد می‌کند. همچنین می‌توان پوشه RTSS نصب‌شده را دستی انتخاب کرد. فایل RTSS در بسته PacePilot قرار داده نشده و بررسی امنیتی دانلود غیرفعال نمی‌شود.

## رابط فارسی و انگلیسی

در بالای نوار کناری، از فهرست `Language / زبان` گزینه `فا` را انتخاب کنید. برای بازگشت به انگلیسی `EN` را بزنید. انتخاب زبان ذخیره می‌شود و لازم نیست برنامه را ببندید. همه دکمه‌های اصلی، پیغام‌ها، منوی کنار ساعت و هشدارها دو زبانه هستند. گزارش عیب‌یابی RTSS به زبان فنی انگلیسی می‌ماند.

## امکانات

- محدودکردن واقعی FPS با RTSS (صفر = نامحدود)، دکمه‌های آماده، نمایش FPS/Frametime زنده و نمودار.
- پروفایل عمومی و اختصاصی هر بازی، میانبرهای سراسری، اجرای خودکار با ویندوز و آیکن کنار ساعت.
- ابزار عیب‌یابی RTSS با تهیه نسخه پشتیبان قبل از ویرایش جایگزین پروفایل.
- هشدار برای تعدادی از بازی‌های دارای ضدتقلب؛ استفاده در همه بازی‌های آنلاین تضمین نمی‌شود.

**سیستم موردنیاز:** Windows 10/11 x64 و .NET Framework 4.x. اینترنت و وجود winget برای نصب خودکار RTSS لازم است؛ ممکن است تأیید Administrator نیاز شود.

**وضعیت تست:** تست GitHub Actions شامل ساخت EXE، تست رابط فارسی و انگلیسی، چیدمان و انتخاب FPS است. نصب واقعی RTSS و تست FPS داخل بازی هنوز باید روی ویندوز آزمایش شوند.

کد PacePilot تحت مجوز MIT منتشر می‌شود؛ RTSS متعلق به ناشر اصلی آن است.
